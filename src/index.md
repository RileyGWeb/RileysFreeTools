# Welcome to Riley's Free Tools

This is a **simple static site** generated with basic SSG capabilities.

## Features

This site includes:

- Simple templating system
- Basic markdown-like content processing
- Configuration-based site settings
- Static asset support

## Getting Started

To build this site, run:

```
npm run build
```

The output will be generated in the *dist* directory.

## About

Riley's Free Tools is a collection of useful utilities and tools, all completely free to use.
